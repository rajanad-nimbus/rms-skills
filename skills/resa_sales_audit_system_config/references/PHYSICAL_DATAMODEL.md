# ReSA System Setup - Physical Datamodel

This reference details the physical schema tables for ReSA system options, error codes, constants, and parameters.

```sql
CREATE TABLE SA_SYSTEM_OPTIONS (
    AUDIT_LEVEL VARCHAR2(1) NOT NULL, -- 'S'=Store, 'T'=Till, 'C'=Cashier
    BALANCING_LEVEL VARCHAR2(1) NOT NULL,
    LOCK_TIMEOUT_MINUTES NUMBER(4) DEFAULT 30,
    POST_LEAD_TIME_DAYS NUMBER(2) DEFAULT 0,
    CONSTRAINT PK_SA_SYSTEM_OPTIONS PRIMARY KEY (AUDIT_LEVEL)
);

CREATE TABLE SA_ERROR_CODES (
    ERROR_CODE VARCHAR2(25) NOT NULL,
    ERROR_DESC VARCHAR2(250) NOT NULL,
    ERROR_IMPACT VARCHAR2(10) NOT NULL, -- 'FATAL', 'WARNING'
    SYSTEM_IND VARCHAR2(1) DEFAULT 'Y',
    CONSTRAINT PK_SA_ERROR_CODES PRIMARY KEY (ERROR_CODE)
);
```
